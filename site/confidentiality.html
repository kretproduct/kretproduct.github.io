Политика конфиденциальности

Редакция от 6 ноября 2026 года

1. Общие положения

  1. Политика определяет, как , ИНН (далее — Исполнитель), обращается с информацией, которую получает от посетителей сайта и заказчиков услуг (далее — Пользователь).
  2. Пользуясь сайтом и обращаясь к Исполнителю, Пользователь соглашается с этой политикой. Если Пользователь не согласен с ней, ему следует не передавать Исполнителю свои сведения.
  3. Порядок обработки персональных данных подробно описан в Политике обработки персональных данных. Эта политика её дополняет.

2. Какую информацию мы считаем конфиденциальной

  • персональные данные Пользователя: имя, телефон, имя пользователя в Telegram, адрес электронной почты;
  • сведения о проекте и бизнесе Пользователя, которые он сообщил в переписке или на созвонах: ниша, клиенты, цены, планы, финансовые показатели;
  • материалы, которые Исполнитель подготовил для Пользователя: документы, тексты, таблицы, сценарии;
  • содержание переписки и созвонов между Пользователем и Исполнителем.

3. Как мы используем информацию

Только для того, чтобы согласовать и оказать услуги, принять оплату, выдать чек и ответить на обращения. Исполнитель не использует сведения Пользователя для других целей, не продаёт их и не передаёт для рекламы.

4. Неразглашение

  1. Исполнитель не раскрывает третьим лицам конфиденциальную информацию Пользователя без его письменного согласия, в том числе после окончания работ.
  2. Исполнитель не публикует материалы, подготовленные для Пользователя, и не упоминает его как клиента без его согласия.
  3. Если для работы над проектом с согласия Пользователя привлекаются подрядчики (дизайнер, монтажёр, специалист по рекламе), им передаются только те сведения, которые нужны для их части работы.

5. Когда информация может быть передана

  • банку, через который проводится оплата, — в объёме, нужном для проведения платежа;
  • ФНС России — сведения о сумме оплаты для формирования чека в приложении «Мой налог»;
  • государственным органам — только по их законному требованию в случаях, предусмотренных законодательством РФ.

6. Платёжные данные

Исполнитель не получает и не хранит данные банковских карт. Номер карты и код CVC/CVV Пользователь вводит на защищённой платёжной странице банка. Передача данных защищена по стандарту PCI DSS.

7. Файлы cookie и аналитика

Сайт не использует системы аналитики, рекламные счётчики и cookie для отслеживания посетителей, не собирает данные через формы. Хостинг сайта (GitHub Pages) может вести технические журналы обращений, например IP-адрес и время запроса, для обеспечения работы и безопасности сайта.

8. Защита информации

Исполнитель хранит сведения и материалы Пользователя в защищённых паролем учётных записях, ограничивает к ним доступ и не передаёт их по открытым каналам без необходимости. Сайт работает по защищённому протоколу HTTPS.

9. Срок хранения

Сведения хранятся, пока действует договор, и ещё 3 года после его исполнения, если более долгий срок не требуется по закону. Пользователь может в любой момент попросить удалить свои сведения, написав на . Ответ направляется в течение 10 рабочих дней.

10. Изменение политики

Исполнитель может обновлять политику. Новая редакция действует с момента публикации на сайте. Дата редакции указана в начале страницы.
